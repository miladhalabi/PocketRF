PocketRF Web Flasher

This is a radio transmitter. Jamming is illegal in most jurisdictions and normal transmission is regulated too. Read LEGAL.md before you transmit. Never transmit without an antenna attached.

Install

  1. Build the hardware — see docs/hardware.md.
  2. Connect the XIAO ESP32-C3 by USB.
  3. Click Connect and pick the serial port.
  4. Approve the erase prompt on first install.
Your browser does not support Web Serial. Use a desktop Chrome, Edge, or Opera — no mobile browser works here. This page is not allowed to use Web Serial (needs HTTPS or localhost).

Notes

  • First install wipes the flash — back up anything you've saved on the device.
  • After flashing, the device advertises over BLE as XIAO-RF-BLE.
  • If the port doesn't show up: hold BOOT, tap RESET, release BOOT.
  • Needs Chrome / Edge / Opera on desktop. Safari and Firefox do not support Web Serial.
